# 방법 1: Interactive Shell이 없는 경우
1. 대량 생성 로직을 개발
2. 해당 로직을 API로 노출
3. 배포
4. csv파일을 S3에 업로드
5. presigned URL을 파라미터로 API 호출

<!--
대화형 쉘이 없는 경우는 다음과 같은 방식으로 처리하게 될겁니다.
